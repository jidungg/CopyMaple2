# 02. Engine (엔진 DLL)

`Engine` 프로젝트는 게임에 종속되지 않는 범용 기능을 제공하는 DLL입니다. 소스는 `Engine/Private/`(구현)와 `Engine/Public/`(헤더)으로 나뉩니다. 모든 공개 클래스는 `BEGIN(Engine) ... END` 매크로로 `Engine` 네임스페이스에 들어가며 `ENGINE_DLL`로 export됩니다.

## CGameInstance — 엔진 Facade

`Engine/Public/GameInstance.h`. 싱글톤이며 내부에 모든 매니저를 보유하고, 게임 코드는 거의 모든 엔진 기능을 이 클래스를 통해 호출합니다.

보유 매니저 목록:

| 매니저 | 책임 |
|--------|------|
| `CGraphic_Device` | D3D11 Device/Context/SwapChain, 백버퍼·깊이버퍼 |
| `CInput_Device` | DirectInput 키보드/마우스 상태 |
| `CTimer_Manager` | 명명된 타이머별 TimeDelta |
| `CLevel_Manager` | 현재 레벨 보관, `Open_Level` 전환 |
| `CPrototype_Manager` | 오브젝트/컴포넌트 원형 등록·복제 |
| `CObject_Manager` | 레벨×레이어별 게임오브젝트 리스트, RayCast |
| `CPipeLine` | World/View/Proj 행렬, 카메라 위치 |
| `CRenderer` | 렌더 그룹별 드로우 (아래 참조) |
| `CController` | 입력으로 Pawn(주로 Player) 빙의(Possess) |
| `CUIManager` | UI 오브젝트 등록, 마우스 오버 판정 |
| `CLight_Manager` | 라이트 등록 및 디퍼드 라이팅 |
| `CPhysics` | 물리 |
| `CEventManager` | 이벤트 push/trigger/dispatch, pre/post 콜백 |
| `CCollisionManager` | 레이어 간 충돌 매트릭스 |
| `CTarget_Manager` | 렌더 타겟(MRT) 생성/바인딩 — 디퍼드 G-Buffer |
| `CCollider_Frustum` | 프러스텀 컬링 |
| `CFontManager` | 커스텀 폰트 로드·렌더 |
| `CSoundManager` | BGM/SFX 재생 (DirectSound) |

`ENGINE_DESC`(hInstance, hWnd, isWindowed, iNumLevels, 뷰포트 크기)로 `Initialize_Engine`을 호출해 부팅합니다.

## 렌더링 (Deferred Rendering)

`CRenderer` (`Engine/Public/Renderer.h`)는 오브젝트를 **렌더 그룹**으로 분류해 순서대로 그립니다.

```
enum RENDERGROUP { RG_PRIORITY, RG_NONBLEND, RG_NONLIGHT, RG_BLEND, RG_UI, RG_END };
```

렌더 순서: `Render_Priority` → `Render_NonBlend`(G-Buffer 기록) → `Render_Lights`(라이트 누적) → `Render_Final`(디퍼드 합성) → `Render_NonLight` → `Render_Blend`(반투명) → `Render_UI`. `_DEBUG` 빌드에서는 `Render_Debug`로 콜라이더·렌더타겟을 시각화합니다.

- 게임오브젝트는 `CGameInstance::Add_RenderObject(group, this)`로 매 프레임 렌더 큐에 등록합니다.
- 디퍼드 라이팅은 `CTarget_Manager`의 MRT(G-Buffer)와 `Engine/Bin/ShaderFiles/Shader_Deferred.hlsl`로 처리합니다.

## 상태 머신 / 이벤트

- **StateMachine**: `CStateMachine` + `CState` + `CTransition` + `CCondition`(int/float/bool/trigger). 몬스터·NPC의 애니메이션 상태 전이에 사용 (클라이언트의 `MonsterAnimStateMachine` 등).
- **Event**: `CEventManager`가 `CEvent`를 큐에 받아 `Dispatch_Event`로 처리. `IEventHandlerWrapperInterface` / `CEventHandlerWrapper`로 pre/post 콜백을 등록.

## 베이스 & 공통 정의

- `CBase`: 모든 클래스의 루트. 참조 카운트(`AddRef`/`Release`)와 `Free()` 가상 소멸 패턴.
- `Engine_Defines.h`: D3D11/DirectXTK/Effects11 헤더 일괄 포함, STL 일괄 포함, 핵심 enum(`PROTOTYPE`, `KEY`, `KEY_STATE`, `MOUSE_KEY`, `TEXTURE_TYPE`, `CONDITION_TYPE` 등), `_DEBUG` 메모리 누수 추적 매크로(`DBG_NEW`).
- `Engine_Typedef.h` / `Engine_Macro.h` / `Engine_Struct.h` / `Engine_Function.h`: 타입 별칭(`_float`, `_uint`, `_wstring`, `_matrix` 등), `BEGIN/END`·`DECLARE_SINGLETON`·`MSG_BOX`·`Safe_*` 매크로, 공용 구조체(`ENGINE_DESC`, `LIGHT_DESC`, `TRANSFORM_KEYFRAME` 등), 유틸 함수.
- `json.hpp`: nlohmann/json. 데이터 직렬화에 광범위하게 사용.
