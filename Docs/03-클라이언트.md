# 03. Client (게임 로직)

`Client` 프로젝트는 실제 게임 콘텐츠를 구현합니다. 소스 구성:

- `Client/Default/` — 진입점(`Client.cpp`/WinMain), `stdafx`, 리소스, 클라이언트 유틸
- `Client/Private/` — 구현(`.cpp`)
- `Client/Public/` — 헤더(`.h`)
- `Client/Bin/` — 실행 디렉토리(리소스·셰이더·데이터·DLL)

핵심 enum과 전역 상수는 `Client/Public/Client_Defines.h`에 집중되어 있습니다(레벨/레이어/아이템/스킬/몬스터/퀘스트 ID 등 + JSON 직렬화 매핑).

## 앱 & 레벨

| 클래스 | 역할 |
|--------|------|
| `CMainApp` | 게임 루프(Update/Render), 엔진 초기화, 각종 DataBase·매니저 수명 관리 |
| `CLoader` | 레벨별 프로토타입(모델·텍스처·오브젝트 원형) 비동기 로드 |
| `CLevel_Loading` | 로딩 화면. 백그라운드 로드 완료 후 목표 레벨로 전환 |

**레벨들** (각각 `CLevel` 파생): `Level_Logo`, `Level_Henesys`(헤네시스 마을), `Level_Home`(마이홈/건축), `Level_BayarPeak`(보스), `Level_HuntingPlace` / `Level_HuntingPlace2`(사냥터), `Level_GamePlay`(공용 베이스). 각 레벨은 자신의 레이어에 오브젝트를 배치하고, 맵 구성은 `Resources/Json/<레벨>.json`에서 읽습니다.

## 캐릭터 / 전투

```
CGameObject
 └─ CRenderObject / CModelObject (모델 보유 오브젝트)
      ├─ CBoneModelObject / CHumanModelObject
      └─ CCharacter ── CPlayer / CMonster / CNPC
```

| 클래스 | 설명 |
|--------|------|
| `CCharacter` | 캐릭터 공통 기반(상태·이동·피격) |
| `CPlayer` | 플레이어. `CController`가 입력으로 빙의. 장비/외형/스킬 보유 |
| `CMonster` | 몬스터. `CMonsterAnimStateMachine`으로 상태 전이, `CMonsterSpawner`가 생성 |
| `CNPC` | NPC. 대화(`CConversation`)·퀘스트 제공, `CNPCSpanwer`가 생성 |
| `CStatus` | HP/SP/EP/EXP/레벨 등 스탯 |
| `CWeapon` / `CAttachableBodyPart` / `CFace` / `CFaceTexture` | 장비·신체부위·얼굴 부착물(본 미믹 기반) |
| `CHumanModelObject` | 사람형 캐릭터의 파츠 조립(머리/몸/장비) |

**스킬 & 투사체**: `CSkill` / `CSkillManager`(+ `SkillData.json`)가 스킬 정의를 관리. 스킬 종류는 `CBasicAttack`, `CMagicClaw`, `CFlameWave`, `CFireTornado`, `CKindling`, `CBBQParty`, `CFakeMeteor`, `CWildFire`, `CTeleport` 등. 발사체는 `CBullet` 기반(`Bullet_MagicClaw`, `Bullet_FireTornado`, `Bullet_Kindling` 등)이며 오브젝트 풀로 재사용. 보스 **Bayar**는 전용 스킬셋(`BayarAttackA~D`, `BayarSkyJump`, `BayarKnockOff`, `BayarStoneSpike`, `BayarPalmStrike`)과 대응 Bullet을 가집니다. 일반 몬스터 스킬: `SnailAttack`, `CrabAttack`, `StumpKick` 등.

스킬 분류 enum(`Client_Defines.h`): `SKILL_CASTING_TYPE`(즉발/패시브/채널링/차징/캐스팅), `SKILL_TARGET_TYPE`(SELF/ENEMY/ALLY), `SKILL_RANGE_TYPE`(근접/단일/프러스텀/구/실린더), `SKILL_COST_TYPE`(SP/EP).

## 이펙트 시스템

NIF에서 변환된 데이터를 기반으로 한 자체 이펙트 엔진. `CEffectManager`(싱글톤)가 `EffectData.json`을 읽어 관리합니다.

- 데이터/모델: `CEffect`, `CEffModel` / `CEffModelObject`, `CEffMesh`, `CEffBone`
- 컨트롤러: `CEffController` / `CEffConcreteController` / `CEffControllable` — 시간에 따른 변형/알파/색/텍스처 변환 제어 (`EFF_CTRL_TYPE`: Transform/Alpha/MaterialColor/TextureTransform/TextureFlip)
- 머티리얼/텍스처: `CEffMaterialProperty`, `CEffTexturingProperty`, `CEffTextureSlot` (`EFF_TEX_TYPE`: Base/Dark/Detail/Gloss/Glow/Bump/Normal/Parallax/Decal0~3)
- `Default/EffFlipController` — 텍스처 플립 애니메이션
- 이펙트 종류(`EFF_TYPE`): MODEL / SOUND / DAMAGE_FONT / VIBRATION

## 지형 / 월드 / 건축

마이홈은 큐브 기반 건축 시스템을 가집니다.

| 클래스 | 설명 |
|--------|------|
| `CTerrainObject` / `CCubeTerrain` | 지형 블록, 큐브형 지형 |
| `COctoTree` | 옥트리 공간 분할(컬링/충돌 최적화) |
| `CBuilder` / `CBuildPreview` | 건축 모드(블록 배치 미리보기·확정) |
| `CPortal` / `CPortalTerrainObject` / `CTeleport` | 레벨 간 이동 포탈 |
| `CSpawner` / `CMonsterSpawner` / `CNPCSpanwer` | 스폰 지점 |
| `CWayFinder` | 길찾기/경로 |
| `CInteractable` / `CWorldItem` | 상호작용 오브젝트 / 월드에 드롭된 아이템 |

건축 아이템 분류(`Client_Defines.h`): `BUILD_ITEM_TYPE`(GROUND/DEFORM/FLOOR/WALL/CUBRIC/FUNCT/NATURE/PROP/STRUC/각종 SPAWNER/PORTAL), `BUILD_ITEM_BLOCK_TYPE`(CubeCube/CubeMesh/MeshCube/MeshMesh).

## 카메라

- `CCamera_Trace` — 플레이어 추적(쿼터뷰) 카메라
- `CCamera_Free` — 자유 이동(디버그/제작) 카메라

## 데이터베이스 (싱글톤, JSON 로드)

게임 정적 데이터는 `Resources/Json/`의 JSON에서 로드됩니다.

| 클래스 | 데이터 파일 | 내용 |
|--------|-------------|------|
| `CItemDataBase` | `EquipItemData` / `DecoItemData` / `ConsumableItemData` / `ETCItemData` / `ETCBuildItemData` | 아이템 정의 |
| `CSkillDataBase` (`SkillManager`) | `SkillData.json` | 스킬 정의 |
| `CMonsterDataBase` | `MonsterData.json` | 몬스터 스탯·드롭 |
| `CNPCDataBase` | `NPCData.json` | NPC·대화 |
| `CQuestDataBase` | `QuestData.json` | 퀘스트 |
| `CDropTable` | `DropTable.json` | 드롭 확률표 |
| `CPlayerInfo` | `PlayerData.json` | 플레이어 초기 데이터 |

아이템 시스템: `CItem` / `CSlotItem` / `CInventory`(싱글톤) + 슬롯 클래스들(`InvenEquipSlot`, `InvenConsumableSlot`, `InvenDecoSlot`, `InvenBuildSlot`, `InvenETCSlot`). 아이템 분류 enum: `ITEM_TYPE`(EQUIP/DECO/CONSUMABLE/BUILD/ETC), `ITEM_GRADE`(NORMAL~MYTHIC), `EQUIP_ITEM_TYPE`(HAT/TOP/.../WEAPON/EAR).

퀘스트: `CQuest` + `QUEST_STATE`(미수락/수락/완료), `QUEST_CONDITION_TYPE`(몬스터 처치/아이템 수집).

## UI 시스템

UI는 `CUIObject`(엔진) 기반의 풍부한 위젯 계층으로 구성됩니다. `CUIBundle`(싱글톤)이 전역 UI를 묶고, `CCanvas`/`CUIContainer`/`CUIPanel`이 레이아웃을 담당합니다.

- **기본 위젯**: `UIIcon`, `UIButton`, `UIFont`, `UIBar`, `UIPanel`, `UIScroller`/`UIScrollButton`, `UIList`/`UIListItemEntry`/`UIListSelector`, `UIVerticalFill`
- **HUD/전투**: `UIHPBar`, `UIEXPBar`, `UICastingBar`, `UIMainHUDGuage`, `UIHUDMonsterHPBar`, `UIDamgCount`(데미지 폰트), `UIQuickSlot`/`UIQuickSlotBundle`
- **월드 부착 UI**: `WorldUIObject`, `WorldUIHPBar`(몬스터 머리 위 HP)
- **인벤토리**: `UIInventory`, `UIInvenSlot`/`UIInvenSlotEntry`, `UIInvenItemList`, `UIInvenTabButton`, `UIItemIndicator`
- **캐릭터 정보**: `UIPlayerInfo`, `UIPlayerInfoDashBoard`, `UIPlayerInfoSlot`, `UIStatUpButton`, `UIModelPad`(3D 모델 미리보기)
- **대화/퀘스트**: `UINPCDialog`, `UIHomeDialog`, `UIChatOption`, `UIQuestGuide`/`UIQuestGuideBundle`
- 공용: `UICommonWindow`, `UISlot`/`UIInvenSlot`, `UIBundle`

데미지 폰트 종류(`DAMG_TYPE`): 플레이어 일반/크리티컬, 몬스터 일반/크리티컬, 힐.

## 이벤트

클라이언트 이벤트(`EVENT_ID`): `CREATE_OBJ`(`CreateObjEvent`), `DEAD_OBJ`(`DeadObjEvent`), `LEVEL_CHANGE`(`LevelChangeEvent`), `HIT`(`HitEvent`). 엔진의 `CEventManager`를 통해 디스패치됩니다. `EventData.json`에 정의가 있습니다.
